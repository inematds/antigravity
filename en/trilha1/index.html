🛰️ What is AntiGravity & the 3-layer cake

The definition of AntiGravity, the mental map of the 3 layers of AI tools, and why code is “the final layer.”

What it is:

A Google code editor powered by AI agents that runs on your machine and edits real files — you give it instructions in natural language.

Why learn:

It's the most direct way to move beyond "dragging blocks" and build complete applications without mastering syntax.

Key concepts:

Agents · natural language · local environment · Gemini 3 Pro / Claude / other models.

What it is:

A mental map: top = visual tools (Make/n8n), middle = cloud vibe coding, base = local environment (AntiGravity).

Why learn:

Knowing which layer you're in helps you choose the right tool and understand what each one sacrifices.

Key concepts:

Abstraction vs. control · cloud simplifies at the cost of functionality · local = full control.

What it is:

Deterministic = a fixed, repetitive workflow (ideal for Make/n8n). Agentic = AI writes and manages code for changing problems.

Why learn:

The question “does this change or is it always the same?” determines which approach to use.

Key concepts:

Fixed workflow · adaptive workflow · complexity · autonomy.

What it is:

Every visual tool is just an interface over code. Mastering code (with AI) is the foundation that won’t become obsolete.

Why learn:

It makes you immune to the fear of “the next trendy tool”—you’re already at the layer that does it all.

Key concepts:

Interface vs. foundation · skill longevity.

What it is:

Cursor, Windsurf, and AntiGravity are competing AI IDEs. The course uses AntiGravity, but the principles apply to all of them.

Why learn:

You learn a concept, not a button — and can switch tools without starting over.

Key concepts:

Native capabilities · skill portability.

What it is:

For simple, repetitive, and stable tasks (e.g., “filled form → add to list”), a no-code workflow is faster and cheaper.

Why learn:

Using the right tool saves time — not everything needs to become an app.

Key concepts:

Cost-effectiveness · simplicity · maintenance.

What it is:

Each module includes concepts, step-by-step instructions, an example, an exercise, and ready-to-use prompts. Mark each section as read to track your progress.

Why learn:

Knowing the structure helps you study methodically and pick up where you left off.

Key concepts:

Saved progress · prompt library · hands-on practice.

⚖️ No-code automation vs. AI-powered apps

When to use visual builders (Make/n8n) and when to move to agentic development — and why it's worth understanding both.

What it is:

Visual workflows with fixed steps: trigger → action → action. Great for predictable tasks that don’t change.

Why learn:

It's the simplest and cheapest way to solve repetitive problems.

Key concepts:

Trigger · modules · webhook · predictability.

What it is:

You describe the goal, and AI writes/edits code, tests, and fixes it — for complex, evolving problems.

Why learn:

Unlocks what a fixed workflow can’t handle: complete apps and unlimited functionality.

Key concepts:

Autonomy · adaptation · generated code.

What it is:

Visual tools are a polished layer over JSON/code. Copy a workflow and you can see the JSON behind it.

Why learn:

Understanding this demystifies “code” and shows that you were already working with it without realizing it.

Key concepts:

Abstraction layer · JSON · visual interface.

What it is:

A decision guide: simple, stable task → no-code; complex problem with its own interface and logic → agentic app.

Why learn:

Avoids using a cannon to kill a fly (or vice versa).

Key concepts:

Selection criteria · cost · complexity.

What it is:

No-code and agentic apps complement each other; understanding workflows makes you better at directing agents (and vice versa).

Why learn:

You gain a broader range of solutions.

Key concepts:

Complementarity · breadth of experience · integration (MCP).

What it is:

Cloud vibe coders are like an IKEA house: they deliver something ready-made, but with fixed structures. Locally, you can build however you want.

Why learn:

Shows the trade-off between speed and freedom.

Key concepts:

Convenience vs. control · cloud limits.

⚙️ Complete environment setup

Install everything, understand the interface, and import/run your first project on localhost.

What it is:

Download and install the app from the official site (antigravity.google).

Why learn:

It’s the first concrete step—without it, nothing runs.

Key concepts:

Official download · installation.

What it is:

Node.js is the "engine" that lets AI create and run projects at the level of your computer.

Why learn:

Without it, the agent can't run most apps locally.

Key concepts:

Runtime · npm · local environment.

What it is:

GitHub is where files are stored and versioned. Repositories can be public (anyone can see them) or private.

Why learn:

It's where you import projects and where you publish yours.

Key concepts:

Repo · visibility · collaboration.

What it is:

Import a repo (by pasting the URL) and ask it to run — it starts up at a local address (localhost) that only you can see.

Why learn:

It's the basic cycle: bring in code, run it, see it on screen.

Key concepts:

Import · localhost · preview.

What it is:

The terminal is how you communicate with the computer using text: install things, run commands, perform actions.

Why learn:

Many actions (installing packages, running builds) go through it.

Key concepts:

CLI · command · installation.

What it is:

Rule of thumb: one model strong in design for layout, another strong in reasoning for code and troubleshooting.

Why learn:

Choosing the right model greatly improves the results.

Key concepts:

Model selection · use case.

What it is:

Command panel, file navigation, “publish to GitHub,” and Agent Manager (where you manage multiple agents).

Why learn:

Getting to know the interface speeds up everything that comes next.

Key concepts:

Panel · Agent Manager · workspaces.

What it is:

The agent opens the browser, clicks buttons, checks the result on screen, and corrects itself — with no extra plugins.

Why learn:

It’s an advantage that saves a lot of back-and-forth.

Key concepts:

Browser control · self-correction.
