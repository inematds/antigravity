⬇️ Instalar AntiGravity

El primer paso concreto es el más sencillo: descargar el AntiGravity a partir del sitio oficial — antigravity.google — e instalarlo como instalas cualquier otra aplicación en tu computadora.

🧭 Concepto principal

Aquí no hay ningún secreto. Es un programa que se ejecuta en tu computadora, como un editor de texto o un navegador. Descárgalo de la fuente oficial, abre el instalador y sigue los pasos.

  • •Accede al sitio oficial (antigravity.google): evita los enlaces de terceros.
  • •Descarga la versión para tu sistema (Windows, macOS o Linux).
  • •Instala y abre — es el mismo flujo que en cualquier app.

⚙️ Instalar Node.js

O Node.js es el "motor" que permite que la IA cree y ejecute proyectos al nivel de tu computadora. Descárgalo de nodejs.org. Sin él, la mayoría de las apps simplemente no se ejecuta localmente.

✓ Con Node.js instalado

  • ✓La IA puede ejecutar el proyecto en tu computadora
  • ✓Instalas dependencias de las apps
  • ✓localhost funciona normalmente

✗ Sin Node.js

  • ✗La mayoría de las apps no se inicia localmente
  • ✗Los comandos de instalación fallan
  • ✗Te trabas desde el primer proyecto

💡 Consejo práctico

En nodejs.org, elige la versión LTS (soporte a largo plazo): es la más estable y la recomendada para la mayoría de las personas. Después de instalar, basta con volver a abrir AntiGravity.

🐙 GitHub: repositorios

O GitHub es donde se guardan y versionan los archivos de los proyectos. Cada proyecto vive en un repositorio (o «repo»). De ahí importas código listo y allí publicas el tuyo más adelante.

🌍 Repositorio público

  • •Cualquier persona puede verlo e importarlo
  • •Ideal para templates y ejemplos
  • •Se aprende mucho leyendo código abierto

🔒 Repositorio privado

  • •Solo tú (y quien invites) tienes acceso
  • •Ideal para proyectos tuyos o de clientes
  • •La misma estructura, visibilidad cerrada

🟢 El botón verde "Code"

En cualquier repositorio, el botón verde "Code" revela la URL del repo. Esta es la URL que vas a pegar en AntiGravity para importar el proyecto. Recuerda este hábito: "Code" → copiar URL.

📥 Importar proyecto + localhost

Con la URL del repo a mano, el ciclo es directo: tú pega la URL y le pide al agente que lo importe. Después le pide que ejecutar, y el proyecto queda disponible en una dirección local (localhost:porta) que solo tú puedes ver.

1

Traer el código

Pega la URL del repositorio y pídele al agente que importe el proyecto a tu máquina.

2

Ejecutar

Pídele al agente que inicie el proyecto. Instala lo necesario y lo pone en marcha.

3

Ver en pantalla

Se publica en una dirección local, como localhost:3000. Ábrelo en el navegador y mira la app funcionando, solo en tu máquina.

🌐 Qué es "localhost"

"localhost" es tu propia computadora funcionando como servidor. La puerta (p. ej.: 3000, 5173) es solo el "canal" en el que la app está escuchando. Es una dirección privada: nadie en internet puede verla, solo tú.

⌨️ La terminal / CLI

O terminal (también llamado CLI, por «interfaz de línea de comandos») es como hablas con la computadora por texto, en lugar de clics. Muchas acciones —instalar cosas, ejecutar comandos, hacer builds— pasan por ahí.

ejemplos de comandos en la terminal
npm install      # instala o que o projeto precisa
npm run dev      # roda o projeto em modo de desenvolvimento
node --version   # mostra a versão do Node.js instalada

La buena noticia: en el flujo agentic, la mayor parte del tiempo es el agente quién escribe esos comandos por ti. Pero entender que el terminal existe —y que es solo «la computadora escuchando texto»— quita el miedo cuando necesitas pegar un comando manualmente.

💡 Consejo práctico

No memorices comandos. Cuando necesites uno, pídele al agente: "¿qué comando ejecuto para [objetivo]?". La terminal deja de intimidar cuando la tratas como otro canal de conversación.

🧠 Elegir el modelo según la tarea

AntiGravity te permite elegir el modelo de IA que va a trabajar. La regla práctica es sencilla: usa un modelo potente en diseño para diseño, y uno fuerte en razonamiento/código para lógica y troubleshooting.

💡 Consejo práctico

Para un uso profesional y continuo, un plan de pago puede con el volumen: ejecutas más tareas sin chocar con límites. Empieza gratis para probar la herramienta; sube de plan cuando el uso lo justifique.

🖥️ La interfaz

Vale la pena conocer las cuatro áreas principales de la pantalla. No necesitas memorizar nada: solo saber dónde está cada cosa para no perderte cuando empieces a construir.

1

Panel de comandos

Dónde conversas con el agente y le pides lo que quieres. Es el corazón del flujo.

2

Navegación de archivos

La lista de carpetas y archivos del proyecto. Es útil para ver qué creó la IA y dónde.

3

"Publicar en GitHub"

Un atajo para enviar tu proyecto a un repositorio cuando esté listo.

4

Agent Manager

Gestiona varios agentes y proyectos al mismo tiempo: no te quedas atrapado en una sola conversación.

📂 Crear tu workspace

Para iniciar un espacio de trabajo, usa File → Open Folder y apunta a la carpeta del proyecto. Ese es el gesto que le dice a AntiGravity: "es aquí donde vamos a trabajar".

🌐 Control del navegador + autocorrección

Este es el recurso que cambia las reglas del juego: el agente abre el navegador, hace clic en botones, comprueba el resultado en pantalla y se autocorrige — sin necesidad de plugins. «Ve» lo que ocurrió y se ajusta por sí solo.

En la práctica, eso ahorra muchos intercambios: en vez de probar, copiar el error, pegarlo de vuelta y pedir que lo corrija, el agente cierra ese ciclo por sí solo. Tú describes, él hace, verifica y corrige.

🔬 Ejemplo práctico

Vamos a unirlo todo en un solo gesto. Importa un plantilla de landing page de un repositorio público y súbelo a localhost:

  • 1.Busca la URL de un repo público con una plantilla sencilla de landing page.
  • 2.Pega en AntiGravity y pídele que lo importe; después, pídele que lo ejecute.
  • 3.Abre la dirección local (ej.: localhost:3000) y mira el sitio en tu máquina.

En pocos minutos, pasas de cero a tener un sitio funcionando localmente, sin haber escrito una sola línea a mano.

🏋️ Ejercicio

Deja tu entorno realmente listo. Completa todo el proceso:

  1. Instala AntiGravity (de antigravity.google) y el Node.js (de nodejs.org, versión LTS).
  2. Importa uno cualquier repositorio público (una plantilla simple sirve).
  3. Ejecuta en localhost e anota el puerto que apareció (p. ej., 3000, 5173).

Si viste abrirse la app en el navegador, tu entorno está listo para la Trilha 2, donde construiremos la primera app desde cero.
